# BM 분류 총람

BM을 게임 단위가 아니라 **BM 자체의 종류**로 쪼갠다. 각 항목은 정의 → 역사 → 대표 사례 → 어울리는 재미 요소/장르 → 부작용 순으로 쌓는다.

새 항목은 [`_template.md`](_template.md) 구조를 따르고, 작성 절차는 저장소 루트의 `workflows/add-bm-entry.md` 참고.
