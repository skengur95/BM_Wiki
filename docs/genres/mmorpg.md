# MMORPG

**핵심 재미 요소:** 캐릭터 성장의 누적, 아이템/장비 소유욕, 그리고 서버 내 사회적 위계(누가 더 강한가, 누가 더 좋은 장비를 가졌는가)가 재미의 축이다. 콘텐츠 자체보다 "내가 이 세계에서 어떤 위치인가"가 지속 플레이의 동력이 된다.

**상태:** 초안 (연혁 일부 검증 필요)

## 적합한 BM

- [확률형 아이템 / 가챠](../bm-catalog/probability-item.md) — 강화/합성 구조와 결합하면 "위계 상승"이라는 핵심 재미와 직접 맞닿는다. 위계가 재미의 축인 장르이기 때문에 구조적으로 강하게 작동한다.
- [구독형](../bm-catalog/subscription.md) — 초기 MMORPG(예: 리니지, WoW)의 원형 BM. 세계에 지속적으로 머무는 것 자체에 값을 매기는 방식으로, "이 세계에 살고 있다"는 감각과 맞다.
- [VIP / 멤버십](../bm-catalog/vip-membership.md) — 사회적 위계가 핵심 재미이므로, 결제 누적에 따른 가시적 등급 표시(칭호, 이펙트 등)가 특히 잘 작동한다.

## 지양해야 할 BM

- 세션이 짧은 것을 전제로 한 [배틀패스 / 시즌패스](../bm-catalog/battle-pass.md)류를 원형 그대로 이식하면, MMORPG 특유의 "장기 누적" 정체성과 어긋나 단기 이벤트처럼 소비되고 끝날 위험이 있다 (다만 시즌제 콘텐츠 리셋 구조를 가진 최신 MMORPG는 예외일 수 있음 — 검증 필요).

## 시도해볼만한 조합 (검증 안 된 가설)

- 위계를 "숫자"가 아니라 "서사"로 드러내는 코스메틱 결합 — 강함이 아니라 "그 유저가 겪은 서버 역사"를 보여주는 장비/칭호 판매. 페이투윈 논란 없이 위계 재미를 팔 수 있는 방향으로 검증 필요.

## 이 장르의 BM 역사 흐름

- **1998년 9월** — 리니지가 국내 최초로 유료 서비스를 시작, 월정액(구독형) 모델을 오랫동안 유지.
- **2000년대 중반 이후** — 정액제 모델이 전반적으로 저물면서 부분유료화 전환이 업계 표준이 됨. 엔씨소프트도 블레이드앤소울, 아이온에 이어 리니지까지 부분유료화로 전환. *(각 게임의 정확한 전환 연도는 검증 필요)*
- **부분유료화 이후** — 강화/합성형 확률 아이템이 MMORPG의 핵심 매출원으로 자리잡음. 이 흐름은 [확률형 아이템 / 가챠](../bm-catalog/probability-item.md) 문서의 규제 연혁과 직접 연결된다.
