# 네트워크 효과와 양면시장

**한줄 정의:** 사용자가 늘어날수록 서비스 자체의 가치가 커지는 현상(네트워크 효과)과, 서로 다른 두 그룹(예: 광고주-사용자, 판매자-구매자)이 서로를 끌어들이며 함께 성장하는 시장 구조(양면시장, two-sided market)를 가리킨다.

**상태:** 초안

## 개념 설명

### 네트워크 효과: 세 가지 유형

네트워크 효과는 "사용자 수 자체가 상품 가치의 일부"라는 현상이다. 한 사람이 더 가입한다고 그 사람만 이득을 보는 게 아니라, 기존 사용자 전체의 경험도 함께 좋아진다. 이를 세 가지로 나눠 볼 수 있다.

- **직접 네트워크 효과 (direct network effect)**: 같은 그룹 안에서 사용자가 늘수록 가치가 올라가는 경우. 전화망이 대표적 원형이다 — 가입자가 나 혼자면 쓸모가 없지만, 주변에 가입자가 많을수록 전화의 가치가 커진다. 게임에서는 멀티플레이어 타이틀이 여기 해당한다: 동시 접속자가 많을수록 매칭 대기시간이 짧아지고, 랭크마다 상대가 충분히 모여 매칭 품질(비슷한 실력끼리 붙는 정도)도 올라간다.
- **간접 네트워크 효과 (indirect network effect)**: 서로 다른 그룹 사이에서 한쪽이 늘면 다른 쪽도 늘어나는 경우. 예를 들어 사용자가 늘면 그 사용자층을 노리는 광고주가 늘고, 광고주가 늘면 광고 단가와 콘텐츠 투자 여력이 늘어 다시 사용자 경험이 좋아지는 순환이다. 이 유형이 바로 아래에서 다룰 **양면시장**의 핵심 동력이다.
- **데이터 네트워크 효과 (data network effect)**: 사용자가 늘수록 축적되는 데이터가 늘고, 그 데이터로 매칭·추천·밸런싱 품질이 좋아져 다시 사용자 경험이 개선되는 순환. 매치메이킹 알고리즘, 추천 상점 진열, 이상 유저(어뷰징) 탐지 정확도 등이 여기 해당한다. 사용자가 적은 초기 서버에서는 매칭 알고리즘이 아무리 정교해도 데이터가 없어 제대로 작동하지 않는다.

### 양면시장: Rochet-Tirole (2003)

양면시장(two-sided market) 이론은 장 샤를 로쉐(Jean-Charles Rochet)와 장 티롤(Jean Tirole)이 2003년에 학술적으로 정식화했다 *(검증 필요 — 정확한 논문/발표 시점 및 세부 내용)*. 핵심 통찰은, 플랫폼이 두 개(또는 그 이상)의 서로 다른 사용자 그룹을 동시에 상대하며, 한쪽 그룹에 매기는 가격이 다른 쪽 그룹의 참여량에 직접 영향을 준다는 것이다. 신용카드사가 소비자에게는 연회비를 낮게 매기고 가맹점에는 수수료를 매기는 구조, 게임 플랫폼이 유저에게는 무료로 열어주고 아이템 판매자·광고주에게 과금하는 구조가 전형적인 예다.

### 임계질량과 닭-달걀 문제

양면시장은 출발선에서 구조적인 딜레마를 안고 시작한다: **유저가 없으면 판매자(또는 광고주)가 안 들어오고, 판매자가 없으면 유저도 매력을 못 느낀다.** 이를 "닭이 먼저냐 달걀이 먼저냐" 문제라고 부른다. 이 딜레마를 넘어서기 위해 필요한 최소 규모를 **임계질량(critical mass)**이라 하고, 이 지점을 넘기지 못하면 플랫폼은 양쪽 모두가 텅 빈 채로 고사한다.

임계질량을 넘기기 위해 흔히 쓰는 전략은 다음과 같다.

- **한쪽 그룹에 대한 보조금/무료화**: 가격에 덜 민감한 쪽을 무료 또는 보조금으로 먼저 채우고, 그 규모를 미끼로 다른 쪽 그룹(가격에 덜 민감하지 않은, 즉 지불 의사가 있는 쪽)을 유치한다.
- **인위적 시딩(seeding)**: 초기 판매자·콘텐츠·유동성을 운영진이나 봇, 초청 파트너로 인위적으로 채워 "이미 활발해 보이는" 상태를 먼저 만든다.
- **단계적 지역/서버 출시**: 전체를 한꺼번에 열지 않고 좁은 범위(특정 지역, 특정 서버)에서 먼저 밀도를 채운 뒤 확장한다.

## 이 위키에서의 쓸모 (BM과의 연결)

- **[거래 수수료 / 마켓플레이스](../bm-catalog/marketplace-fee.md)**: 게임 내 경매장·거래소는 전형적인 양면시장이다. 파는 사람이 없으면 사는 사람도 안 모이고, 사는 사람이 없으면 팔 이유가 없다. 거래 수수료형 BM을 설계할 때는 임계질량을 넘기기 전까지 수수료를 낮추거나 면제해 유동성부터 채우는 전략이 필요하다 — 초기부터 수수료를 정상 요율로 매기면 애초에 양쪽 다 안 모여서 거래 자체가 발생하지 않는다.
- **[광고형 BM](../bm-catalog/ad-based.md)**: 사용자 기반이 커질수록 광고주가 매력을 느끼는 전형적인 간접 네트워크 효과 구조다. 초기 사용자가 적은 상태에서 광고 인벤토리를 무리하게 팔려고 하면 광고 단가가 낮게 형성되고, 이는 다시 콘텐츠 투자 여력을 줄이는 악순환으로 이어질 수 있다. 광고형 BM은 어느 정도 사용자 기반(임계질량)을 먼저 확보한 뒤에 본격적으로 수익화하는 것이 일반적이다.
- **멀티플레이어 장르 전반과 "텅 빈 얼리 서버" 문제**: 신작 멀티플레이어 게임이 오픈 초기에 동시 접속자를 확보하지 못하면, 매칭이 안 되거나(직접 네트워크 효과 미달) 경매장에 매물이 없거나(양면시장 미달) 랭킹/길드 같은 사회적 구조가 아예 형성되지 않는다. 이 상태에서는 아무리 좋은 BM을 설계해도 수익화할 대상 자체가 없다 — 서버 통합, 시즌 초기 매칭 범위 확대, 초반 유동성 보조(경매장 판매 수수료 면제 등) 같은 "임계질량 확보 전략"이 BM보다 먼저 와야 하는 경우가 많다.
- 사용자가 계속 남는 이유가 "떠나기 아까워서"인 경우는 네트워크 효과가 아니라 **전환비용/락인**의 영역이다. 이 개념은 별도로 [전환비용과 락인](switching-cost.md) 문서에서 다룬다.
